# Unslop direction — TalentBridge AI

Demo: `/unslop/demo-home.html`  
Status: awaiting approval before live-site changes  
Constraint: keep the blue brand accent

## Severity

**Heavy slop** on the marketing homepage (and related public chrome). Full nine-pass process if approved. App dashboards later in polish mode unless they share the same tells.

## Audit (homepage)

- Radial blue washes + decorative blobs behind hero (`blob-1/2/3`, `tb-match-scene__glow`)
- Blue→sky hue gradient on primary CTAs and accent text
- Uppercase tracked eyebrows (`AI-POWERED WORKFORCE PLATFORM`, footer `FOR COMPANIES`)
- Heading weight 800 + tight tracking across hero and sections
- Dual stacked CTA buttons with title + subtitle each (hero over-actioned)
- Generic headline that could fit many AI products (`Matched by AI`)
- Hype / unverifiable copy (`AI-powered`, `seamless`, `neural matching`, `SOC 2` claims without proof on-page)
- Match scene with glowing AI core, floating % chips, 98% demo score theater
- Footer glow layer + page-directory chrome competing with content
- Jerry guide / floating chrome adding motion noise on first paint
- Inter + heavy weights; hierarchy from weight more than size/color
- Equal feature cards with icon circles repeating the same template rhythm
- Jobs/companies pages partially cleaned already; still inherit some template patterns

## Direction (five lines)

1. **Product.** TalentBridge AI helps India employers and job seekers match on skills, experience, and work mode through jobs, company profiles, and one Smart Card.
2. **Character.** Exact, calm, bridge-steady.
3. **World.** Hiring desks, dossiers, and a bridge between two banks — ink-tinted neutrals with the existing cobalt blue as the single accent (`#1d4ed8` / `#2563eb` family).
4. **Moments.** (1) The match preview: candidate dossier bridged to a role with one fit score. (2) The Smart Card as the physical profile object.
5. **Signature.** A thin bridge-arc line — used on the match preview, Smart Card top edge, and active states — never as a glow.

## Preserve

- Product name TalentBridge AI
- Existing logo mark (flat, no new gradient tile)
- Blue accent as brand color
- Section order and core features on the homepage
- Demo vs live data honesty (illustrative labels stay, quieter wording)

## After approval

Apply nine passes sitewide starting with homepage → jobs → companies → employer/seeker/pricing → auth → remaining public pages. Dashboards in a second wave.
